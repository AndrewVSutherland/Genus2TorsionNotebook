# Extra torsion conditions for contact5/contact6 order-30 family

For every specialization,
  f = Q2*C3
with
  Q2 = (A+3)*x^2 + (B-3)*x + (C+1),
  C3 = 2*x^3 + (A-3)*x^2 + (B+3)*x + (C-1).
The built-in rational 2-torsion comes from this 2+3 factorization.
An additional independent 2-torsion class appears iff
  (i) Q2 splits: Delta2 is a square, or
  (ii) C3 has a rational root rho.

Additional independent 3-torsion condition
Let f=sum c_i*x^i and seek q3=x^2+U*x+V,
ell3=M*x^3+N*x^2+P*x+S with
  ell3^2 - f = M^2*q3^3.
The six coefficient equations are:
  2*M*N - c5 - 3*M^2*U = 0
  N^2 + 2*M*P - c4 - M^2*(3*U^2+3*V) = 0
  2*M*S + 2*N*P - c3 - M^2*(U^3+6*U*V) = 0
  P^2 + 2*N*S - c2 - M^2*(3*U^2*V+3*V^2) = 0
  2*P*S - c1 - 3*M^2*U*V^2 = 0
  S^2 - c0 - M^2*V^3 = 0
For this order-30 family, substitute the c_i from
  f=(x^3+A*x^2+B*x+C)^2-(x-1)^6.
The known 3-torsion is the non-reduced solution
  q3=(x-1)^2, i.e. U=-2, V=1, ell3=+/-h6.
A genuinely additional 3-torsion class must avoid that
branch and pass an independence check in J[3].
