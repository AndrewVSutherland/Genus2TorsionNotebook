# Halving and doubling a rational torsion class

## When to use this

Load this when you have a rational class of order `n` and want a class of
order `2n` on a genus-2 Jacobian — e.g. `4 -> 8`, `6 -> 12`, halving a
3-torsion class inside a `[3,6]` build toward `[3,12]`, or the second halving
of `[4,16]`. Halving is an *algebraic cover*: you write down explicit
equations whose rational points are the curves where the class has a rational
half, then search that cover.

**Read the wall first.** Naive halving to double an order is frequently
obstructed in this project — the simple examples get confined to a
split/nonsimple boundary at an obstructing prime. Prefer **coprime
composition** when a coprime factor exists (see `target-playbook`,
`contact-torsion-constructions`), and do `component-boundary-analysis` when
halving yields only boundary hits. Details in the "halving wall" section.

## 1. General halving conditions

Grounded in `notes/contact6_m36.md`. To halve a rational 3-torsion class `q`
(with its contact cubic `h3`) — i.e. find a class `E'` with `2E' = E`, `E`
the class represented by `q` — introduce

```text
u   = x^2 + alpha*x + beta,
ell = l3*x^3 + l2*x^2 + l1*x + l0.
```

The halving equations are

```text
ell^2 - f = l3^2 * u^2 * q,
ell + h3 == 0 mod q.
```

The first says the half-class sits over `u` and the residual factor is the
target conic `q`; the second is the congruence pinning the correct branch.

Operationally, take the **six coefficients** (degrees `0..5`) of

```text
ell^2 - f - l3^2*u^2*q
```

and the **two coefficients** of the congruence

```text
8L*ell + (8*x^3 + 4*B*x^2 + Delta*x + 8*v^3)   mod q
```

(here `L = 1/m`, and `B, Delta, v` are the cubic-contact quantities from
`contact-torsion-constructions` / `contact6_m36.md`). The sign in the
congruence only chooses `E` or `-E`; since `E` has order 3, existence of a
rational half is unaffected by that sign. On a specialization, the final check
for `[6,6]` is that `TorsionSubgroup(J)` has **two invariant factors divisible
by 6**. The symbolic equations are generated by
`code/contact6_m36_symbolic.m` into
`data/contact6_m36_symbolic_equations.txt`.

## 2. Worked halving of the marked order-6 class (toward `[3,12]`)

From `notes/contact6_m36.md`, section "Halving the marked order-6 class". To
halve the marked contact-6 class `D = P - infinity`, `P = (1, h6(1))`, use the
**centered coordinate** `t = x - 1` and write

```text
h6 = t^3 + A*t^2 + B*t + C,
A = b+3,   C = a+b+2,   B = A+C-2.
```

Then `f = h6^2 - t^6`. A rational half `H` of `D` is represented by

```text
u   = t^2 + p*t + q,
ell = r*t^2 + s*t - C,
```

with

```text
ell^2 - f = -2*A*t*u^2.
```

The sign `ell(0) = -C` makes the residual point `(0, -C)`, hence `2H = D`; the
opposite sign is equivalent after replacing `H` by `-H`. Equating coefficients
gives **four equations** (copy verbatim):

```text
H1 = A*q^2 - C*(B+s) = 0,
H2 = -2*A*C + 4*A*p*q - B^2 - 2*C*r + s^2 = 0,
H3 = -2*A*B + 2*A*p^2 + 4*A*q - 2*C + 2*r*s = 0,
H4 = -A^2 + 4*A*p - 2*B + r^2 = 0.
```

On the open chart `A*C != 0`, **two variables eliminate immediately**:

```text
p = (A^2 + 2*B - r^2)/(4*A),
s = A*q^2/C - B.
```

The two remaining equations in `(A, C, q, r)` are the algebraic halving cover;
they are written by `code/contact6_m36_halveD_symbolic.m` into
`data/contact6_m36_halveD_symbolic.txt`.

## 3. The M(2,12) chart (marked class of order 12)

The halving cover above is the **same two-dimensional family** as the standard
`M(2,12)` chart (from `contact6_m36.md`):

```text
m = (1 - z^2)/(4*(r + 1)),
T = m*x^2 - x + r,
Y^2 = (x - r)^2*(T + 1)^2 + 4*m*x^2*T*(T + 1),
```

where the marked class has **order 12**. Params are `(z, r)` (with `m`
determined). Adding an independent rational 3-torsion direction (see
`contact-torsion-constructions`) then targets `[3,12]`.

The `[3,12]` search on this chart is `code/contact6_m36_halveD_m312_search.m`:
it filters rational `(z, r)` by the necessary finite condition that `J(F_p)`
contain a subgroup compatible with `[3,12]` at every good prime `p != 2,3`,
applies a geometric-simplicity certificate from an irreducible local
`L`-polynomial, then computes exact `TorsionSubgroup`.

The A(12) chart (`f = R*F`, `F = Q^2 + R*ell^2`, params `(p,z,r)`) is a
*different* order-12 normalization used for `[2,24]` work; see
`named-charts-reference`.

## 4. The halving wall

**Statement.** Naive halving to double an order is frequently obstructed: the
simple specializations are confined to a **split/nonsimple boundary at an
obstructing prime**. Prefer coprime composition when the coprime factor
exists; when halving yields only boundary hits, switch to
`component-boundary-analysis` at the obstructing prime rather than extend a
blind height search in the same open chart.

**Evidence (from `contact6_m36.md`, the `[3,12]` boundary analysis).**

- The finite table already shows a strong obstruction on the good open chart:
  `p=5: allowed_312 0`. So any rational `[3,12]` example in this halved-contact
  chart must reduce to the bad/boundary locus modulo `5`.
- Height-30 (`1234321` pairs) and height-40 (`3837681` pairs) runs found
  residue survivors and simple survivors, but **every exact simple survivor
  had torsion `[12]`, never `[3,12]`**.
- The `p=5` component analysis (`code/contact6_m36_halveD_p5_boundary_analysis.m`)
  factors the sextic discriminant over `F_5` as
  `r^6*(r+1)^21*z^2*(z+1)^11*(z-1)^11*H(z,r)`; the known split `[3,12]` example
  reduces to `Rinf + Z0`. In the height-40 component run, all simple-certified
  boundary lifts exact-tested to `[12]`; the only `[3,12]` cases (`z=-5/3,
  r=-3/5`; `z=-5/3, r=-9/35`; `z=-5/4, r=-32/35`) were on the split `Rinf+Z0`
  boundary — Magma finds automorphism group order 4 and two degree-2 subcovers,
  so they are **split/nonsimple**, hence worthless here.

**Corroborating walls elsewhere in the project** (the pattern recurs — the
obstruction is almost always a small-prime boundary, not global emptiness):

- Contact-7 `[28] -> [56]`: the second halving of the order-4 class is
  obstructed modulo `5` (`notes/contact7_family.md`: `p 5 ...
  h4_divisible_by_2 0`, "NO OPEN H4 HALVES"); every rational `[56]` would have
  to reduce to the `p=5` boundary, and none was found.
- `M_1(8,4)` `[4,16]` second halving: on the six smooth `Q_7` strata the
  first half verifies but `P_R` never halves — through height 150 the exact
  second-halving stage is completely quiet
  (`notes/m18_416_component_and_smooth_strata_2026_07_02.md`).
- Contact-6 `[6,6]`: raw halving of the independent 3-torsion class is **not
  enough by itself** because the half's 2-part coincides with the marked
  order-6 class's 2-part; the winning move was NOT halving but an independent
  2-part — the `[1,2,2]` core-cover route (see `contact6_m36.md` and
  `two-rank-and-factor-types`).

**Takeaway.** When you must double an order, first ask: is there a coprime
factor I can compose instead (e.g. reach `24` as `8 x 3`, `45` as `9 x 5`,
`[6,6]` as marked-6 x independent-3 on a 2-rank-2 core)? If yes, prefer that.
If you genuinely must halve, expect a small-prime boundary obstruction and go
straight to `component-boundary-analysis` at the obstructing prime.

## Pitfalls

- **Treating a finite `[2n]`-filter as sufficient.** The finite `J(F_p)`
  divisibility filters for `[3,6]` and `[6,6]` *coincide* in the contact-6
  tests (`contact6_m36.md`); they are necessary only and do NOT replace exact
  rational halving. Always finish with exact `TorsionSubgroup`.
- **Forgetting simplicity.** A halved `[3,12]`/`[6,6]` hit that reduces to a
  split boundary is nonsimple and worthless here. The known `[3,12]`
  specialization `z=-5/3, r=-3/5, m=-10/9` is exactly such a split curve —
  discarded under the simple-only target. Certify simplicity (see
  `simplicity-certificates`) before claiming anything.
- **Extending height instead of doing boundary analysis.** Once the good open
  chart is killed at the obstructing prime (`allowed_312 = 0` mod 5), a bigger
  height box only re-finds boundary curves. Switch to
  `component-boundary-analysis`.
- **Sign of the congruence branch.** `ell + h3 == 0 mod q` vs `ell - h3`: the
  sign only swaps `E` and `-E`, both order 3, so it does not change existence
  of a rational half. Do not spend effort chasing "the wrong sign".
- **Confusing the two order-12 charts.** `M(2,12)` (`m,T,Y` in `(z,r)`) is the
  halved-contact-6 chart for `[3,12]`; the A(12) chart (`f = R*F`,
  `F = Q^2 + R*ell^2`, `(p,z,r)`) is the `[2,24]` descent chart. Different
  families — see `named-charts-reference`.
