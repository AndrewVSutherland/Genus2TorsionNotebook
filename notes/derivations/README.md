# Early drafting and derivation artifacts

These files lived in the `paper/old/` corner of the working repository:
standalone derivations and early drafting artifacts produced by AI
sessions outside the main Magma lab loop, kept here because they document
the multi-model side of the workflow (several were later absorbed, in
corrected or generalized form, into the paper and the lab notes).

| File | What it is |
|---|---|
| `fromgpt.tex` | Early GPT-drafted paper sections (with the authors' colored comment macros). |
| `fromgemini.tex` | A short Gemini derivation note: decoding a Magma factorization of a torsion-divisor function into its geometric structure. |
| `half_divisor_gpt54.tex` | GPT-5.4 derivation: "A Half of the Divisor P_a + P_b − 2∞" (first version). |
| `half_divisor_gpt55.tex` | GPT-5.5 rederivation of the half-divisor criterion (second version). |
| `halving_order4_threefold_gpt55.tex` | GPT-5.5: halving an order-4 point in the universal (2,2,4,4) family. |
| `m2248_equations_gpt55.tex` | GPT-5.5: equations for the cover M(2,2,4,8) over A(2,2,4,4). |
| `handwritten_delta_descent_page.jpeg` | A handwritten notebook page (one of the authors): the δ(D) = g(θ)−h(θ) mod-squares descent computation for the u,v-family. |

Like everything in `notes/`, these are working documents, not refereed
text: derivations may contain errors that were caught later (the two
half-divisor versions exist precisely because the first needed repair).
