\section*{The first double cover}

Let
\[
A_t:\qquad y^2=x(x-t-1)\left(x-\frac{t+1}{t}\right),
\]
and
\[
C_t:\qquad (ab+(a+b)(t+1)+t)^2-4abt=0.
\]

Using the corrected inverse map from Lemma~6.2,
\[
(x,y)\longmapsto (a,b)
=
\left(
\frac{-t(t+1)\bigl(tx^2-(t^2+t+1)x+2y+(t+1)^2\bigr)}{(tx-(t+1)^2)^2},
\frac{-xt}{t+1}
\right),
\]
the second double cover comes from \(b\), while the first comes from \(a\).

Define the two Kummer coordinates
\[
X_b:=-\frac{t+1}{t}\,b=x,
\qquad
X_a:=-\frac{t+1}{t}\,a.
\]
Thus explicitly,
\[
\boxed{
X_a=
\frac{(t+1)^2\bigl(tx^2-(t^2+t+1)x+2y+(t+1)^2\bigr)}{(tx-(t+1)^2)^2}.
}
\]

Now compute
\[
f_1=(a^2-1)(a^2-t^2).
\]
Since
\[
a=-\frac{t}{t+1}X_a,
\]
we obtain
\[
f_1
=
\left(\frac{t^2X_a^2}{(t+1)^2}-1\right)
\left(\frac{t^2X_a^2}{(t+1)^2}-t^2\right)
=
-\frac{t^2}{(t+1)^4}
(-X_a+t+1)(X_a+t+1)(tX_a-t-1)(tX_a+t+1).
\]
Therefore, up to a square in the function field of \(A_t\),
\[
\boxed{
\operatorname{sqrf}(f_1)
=
-(-X_a+t+1)(X_a+t+1)(tX_a-t-1)(tX_a+t+1).
}
\]

Compare this with the corresponding computation for
\[
f_2=(b^2-1)(b^2-t^2):
\]
\[
\operatorname{sqrf}(f_2)
=
-(-x+t+1)(x+t+1)(tx-t-1)(tx+t+1).
\]
Thus the squarefree part of \(f_1\) is exactly the same quartic as for \(f_2\), but with \(x\) replaced by \(X_a\).

It follows that the first double cover
\[
D_a\to A_t,\qquad s_a^2=(a^2-1)(a^2-t^2),
\]
is the pullback of the same genus-one quartic as the second cover, but now along the map \(X_a:A_t\to \mathbf P^1\).

After the same quartic-to-cubic change of variables used for the second cover, this becomes the pullback of the elliptic curve
\[
E_t':\qquad t(t+1)u^2=X(X-1)(X-t^2)
\]
along \(X_a\). In other words,
\[
\boxed{
D_a \cong A_t\times_{\mathbf P^1_{X_a}} E_t',
\qquad
E_t':\ t(t+1)u^2=X(X-1)(X-t^2).
}
\]

So the situation is:
\begin{itemize}
    \item the second cover is pulled back along \(X_b=x\);
    \item the first cover is pulled back along
    \[
    \boxed{
    X_a=
    \frac{(t+1)^2\bigl(tx^2-(t^2+t+1)x+2y+(t+1)^2\bigr)}{(tx-(t+1)^2)^2};
    }
    \]
    \item the two covers are abstractly isomorphic, but they live over different degree-\(2\) maps \(A_t\to \mathbf P^1\).
\end{itemize}

Consequently, the full Klein four cover is best described as the normalization of
\[
\boxed{
A_t
\times_{\mathbf P^1_x} E_t'
\times_{\mathbf P^1_{X_a}} E_t'.
}
\]
That is, both auxiliary elliptic curves are the same \(E_t'\), but one is pulled back along \(x\), while the other is pulled back along \(X_a\).
