# Contact-6 `[6,12]`: the next `E9` weighted layer and the `R3` cover

Date: 2026-07-10.

## Conclusion

The mod-`5` `E9` stratum above `[A:B:T]=[1:0:0]` is not wholly spurious,
but its `16` rational leading points reduce to exactly `4` points at the next
weighted coefficient.  On the `16`-point set the compatibility obstruction is

```text
n - 3*E = 0  in F_5.
```

The four survivors, in the scaled variable order `(E,l,u,w,n,r)`, are

```text
(1,2,2,2,3,1),  (1,3,2,2,3,1),
(4,1,3,3,2,1),  (4,4,3,3,2,1).
```

Every survivor has exactly `25` lifts modulo `25`; direct substitution in the
five exact normalized equations verifies all `100` lifts.  This is a genuine
lift through the next weighted layer, but not yet a proof of an infinite
`5`-adic core branch: the special-fiber Jacobian still has rank `4`, so a
further singular-Hensel/blowup step is required.

The exact `R3` halving equations also survive.  On their natural endpoint
chart they have two smooth points modulo `5`, and these lift uniquely to

```text
(mu,nu) = (4,0), (21,0)  modulo 25.
```

Consequently the exact `R3` cover supplies no further local obstruction at
`5` to any of the four core survivors.  This is only a local statement;
rational `[6,12]` still requires a rational point on the exact halving cover.


## Exact next-layer core equations

At the endpoint use `b=0`, `a=1/e`.  To avoid confusing the cubic-contact
constant coefficient with the endpoint coordinate, write the scaled cubic
constant as `w`.  The `E9` weight

```text
(v(e),v(L),v(U),v(v),v(N),v(R)) = (2,-1,-2,-2,-1,-4)
```

means

```text
e = 5^2*E,
L = 5^-1*l,
U = 5^-2*u,
v = 5^-2*w,
N = 5^-1*n,
R = 5^-4*r.
```

Substitution into the five uneliminated coefficient equations and
multiplication by their minimum powers of `5` gives the following exact
integral system.  In the equations with an endpoint denominator, an
additional unit factor `E` or `E^2` has been used to clear it:

```text
F5 = 2*5*n - 3*u - 6*l^2,

F4 = E*(5^2*n^2 + 2*r - 3*u^2 - 3*w^2 + 15*5^2*l^2)
     - 2*l^2,

F3 = 2*w^3 + 2*5*n*r - u^3 - 6*u*w^2 - 22*5^4*l^2,

F2 = E^2*(r^2 + 2*5*n*w^3 - 3*u^2*w^2 - 3*w^4
           + 15*5^6*l^2)
     - 5^2*l^2,

F1 = E*(2*r*w^3 - 3*u*w^4 - 6*5^8*l^2)
     - 2*5^6*l^2.
```

The script checks these identities symbolically against the original exact
coefficient equations, not merely after reduction.

Modulo `25` the system is

```text
F5 = -3*u - 6*l^2 + 10*n,
F4 = E*(2*r - 3*u^2 - 3*w^2) - 2*l^2,
F3 = 2*w^3 - u^3 - 6*u*w^2 + 10*n*r,
F2 = E^2*(r^2 - 3*u^2*w^2 - 3*w^4 + 10*n*w^3),
F1 = E*(2*r*w^3 - 3*u*w^4).
```


## The next weighted coefficient

The `16` contact-open points of the initial scheme have the compact
description

```text
E^2 = 1,
l^2 = -E,
u = w = 2*E,
r = 1,
n in F_5^*.
```

At each such point `x0`, put

```text
x = x0 + 5*d.
```

The next coefficient is the affine linear system

```text
Jac(F mod 5)(x0) * d = -F(x0)/5  (mod 5).
```

The Jacobian has rank `4` at all `16` points.  Comparing the rank with the
augmented matrix shows that the system is consistent precisely when

```text
n = 3*E.
```

Thus `12` points are obstructed and `4` survive.  Since a consistent rank-`4`
system in six correction digits has `5^(6-4)=25` solutions, each survivor
has `25` lifts.  The code also enumerates those corrections and substitutes
them back into the exact normalized equations modulo `25`.  One lifted
residue above each survivor is

```text
(1,12,22,7,3,6),  (1,13,22,7,3,6),
(4, 6,18,8,2,16), (4,19,18,8,2,16).
```


## Exact `R3` halving cover on the endpoint

For the distinguished Richelot dual write

```text
g = Delta*R1*R2*R3.
```

On `a=1/e`, `b=0`, clear the endpoint denominators by putting

```text
D  = e*Delta = 3 + 5*e,
A1 = e^2*R1
   = (-2*e-3*e^2)*x^2 + (6*e+10*e^2)*x + (1-3*e^2),
A2 = e*R2 = 2*e*x^2-(1+3*e),
R3 = 2-3*x^2.
```

For the direct square-quartic test, balance the halving-line coefficients as

```text
M = mu/e^2,  N = nu/e^2.
```

Then the exact integral quartic is

```text
S = e^4*(R3*(M*x+N)^2 - Delta*R1*R2)
  = R3*(mu*x+nu)^2 - D*A1*A2.
```

If `S=s4*x^4+...+s0`, the exact open-chart cover is

```text
H1 = 8*s4^2*s1 - s3*(4*s4*s2-s3^2) = 0,
H0 = 64*s4^3*s0 - (4*s4*s2-s3^2)^2 = 0,
s4 != 0.
```

The full polynomials are generated by
`code/contact6_m612_weighted_E9_R3.m`; their shapes in
`(total degree, e-degree, mu-degree, nu-degree, terms)` are

```text
H1: (12,12,5,3,38),
H0: (16,16,8,4,77).
```

On the endpoint fiber they factor especially simply:

```text
H1|e=0 = 144*mu^5*nu,
H0|e=0 = -576*mu^6*(mu^2+6*nu^2+9),
s4|e=0 = -3*mu^2.
```

Hence on `s4 != 0` the two mod-`5` solutions are

```text
(mu,nu)=(1,0),(4,0).
```

The Jacobian with respect to `(mu,nu)` has rank `2` at both points.  Relative
Hensel therefore gives two `R3`-halving branches for every fixed
`e in 5*Z_5`.  Since the `E9` scaling has `e=25E`, their reductions modulo
`25` are `(4,0)` and `(21,0)` and are compatible with every next-layer core
survivor.

This exact cover is stronger than the cheap condition that `DB` be a square.
Its local points certify only `Q_5` compatibility; finding a rational point
on `H1=H0=0` for the same rational `e` remains part of the global problem.
