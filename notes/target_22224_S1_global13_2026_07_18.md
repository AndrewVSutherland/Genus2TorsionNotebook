## Why the projective enumeration is exhaustive

Write a point of `P^1(Z/13^5)` as `[N:D]`.  The S1 coefficient tuple is

```text
[-4*D^2, 9*D^2, 30*D^2, (-2166/245)*N^2].
```

The denominator `245` is a unit at 13.  Every primitive pair `[N:D]` has
exactly one of the following normal forms:

1. `D` is a unit: `[N:D]=[t:1]`, with `t` running over all `13^5` residues;
2. `D` is not a unit, hence `N` is a unit:
   `[N:D]=[1:13u]`, with `u` running over all `13^4` residues.

These disjoint charts have `13^5+13^4=399854` points.  For every point the
script applies exactly the same `DeepKey` normalization used by
`target_22224_rank2_deep_padic_filter.m`: permutation, independent signs via
least absolute residues, and common unit scaling are all quotiented out.
The 144 bank rows are normalized by that same function before comparison.

Thus the zero intersection is an exact finite computation; it does not rely
on a height bound, a choice of Mordell--Weil generators, or numerical
continuity of the elliptic map.

## Independent Mordell--Weil period check

The requested coefficient-period calculation was also completed.  For

```text
E: y^2 = x^3 + x^2 + 3392*x + 62288,
G = (152,-2028),  W = (-17,0),
E(Q) = <G> + {0,W},
```

Magma gives

```text
LocalInformation(E,13) = <13,4,1,2,I4,false>.
```

Thus the curve has nonsplit multiplicative `I_4` reduction.  Exact
`13`-adic evaluation gives

```text
v_13(-x(14G)/y(14G)) = 2,
v_13(-x(14*13^k G)/y(14*13^k G)) = 2+k.
```

No multiple `nG`, `1 <= n < 14`, lies in the formal subgroup.  Consequently
the exact order of `G` modulo the depth-`d` formal subgroup is

```text
14*13^(d-2),  d >= 2.
```

At depth five this is `30758` per torsion coset.  The code independently
scalar-multiplies every representative (long repeated-addition walks were
deliberately avoided because this bad-reduction model loses precision) and
finds

```text
depth 5:  2*30758  =  61516 classes, 508 keys, 0 bank hits
depth 6:  2*399854 = 799708 classes, 508 keys, 0 bank hits
```

The depth-six run contains all thirteen first refinements of each depth-five
class.  All `799708` keys agree with their parent depth-five key; the reported
`parent_mismatches` count is zero.

## Removable-base-point correction

After clearing denominators, the quotient map uses

```text
N = -89425*X + 1463*Y + 4228700*Z,
D = -86279*X + 1463*Y - 7215668*Z,
T = N/D.
```

The two displayed linear forms have the common point

```text
B = (440168/121, 292107900/1331) = 3G + W
```

on `E`.  This is a removable base point of this particular polynomial
presentation of the isomorphism.  Cancelling the common local parameter via
the tangent derivatives gives

```text
T(B) = 314319221/337351087,
canonical key = <1,8371,86230,95861>.
```

That key is not in the bank.  The generic deep-filter code classified an
all-zero map evaluation as `T=infinity`, so its one reported S1 infinity
class was actually this `m=3`, torsion-coset-2 base point.  Correcting it does
not change the zero-hit conclusion, but the distinction matters for future
uses of that map.

## Scope and caveat

This is a genuinely global exclusion **relative to the current 144-row
`13^5` tangent bank**.  It does not prove that S1 has no `13`-adic cubic
contact at all: the bank consists of certified final-digit tangent slices
around sampled incidence centers, and the project documentation explicitly
states that it is not exhaustive over every `13^5` direct-contact branch.

Accordingly, S1 is now closed for all searches that use this bank.  Reopening
S1 would only make sense after enlarging the bank with a genuinely new
13-adic component; increasing the Mordell--Weil coefficient bound cannot
help.
