# Rational Points on the Extra-2 Square Conditions

The extra independent `2`-torsion condition from the order-30 family has two
branch square conditions.  After clearing square factors they are:

```text
C_-: y^2 = -(3R^2 - 12R + 13)
          *(365R^6 - 4044R^5 + 18249R^4 - 42664R^3
            + 54039R^2 - 34764R + 8755),

C_+: y^2 = -(7R^2 - 32R + 37)
          *(305R^6 - 3504R^5 + 16761R^4 - 42784R^3
            + 61611R^2 - 47664R + 15595).
```

Both are smooth genus-3 hyperelliptic curves.  They are isomorphic: with

```text
R_+ = (11R - 25)/(5R - 11),
```

one has

```text
f_+(R_+)*(5R - 11)^8 = 256*f_-(R).
```

So it suffices to analyze `C_-`.

## Quotients of `C_-`

Magma finds the non-hyperelliptic involution

```text
R -> (5R - 7)/(3R - 5),
y -> 16*y/(3R - 5)^4.
```

The elliptic quotient is given by

```text
u = (3R^2 - 7)/(3R - 5),
V = 9*y/(3R - 5)^2,

V^2 = -3*(u - 4)*(365u^3 - 4044u^2 + 14064u - 14656).
```

Magma converts this to

```text
E: Y^2 = X^3 + 2880X^2 + 1769472X - 405209088,
rank(E(Q)) = 1,
E(Q)_tors = 0,
generator = (-1536, 6912).
```

The lift condition from `E` back to `C_-` is

```text
Z^2 = 9u^2 - 60u + 84.
```

The composition with the hyperelliptic involution gives a genus-2 quotient

```text
Z^2 = -3*(9u^2 - 60u + 84)
        *(u - 4)*(365u^3 - 4044u^2 + 14064u - 14656).
```

Magma computes

```text
rank Jac = 0,
Jac(Q)_tors = [2,2].
```

The visible rational points on this genus-2 quotient are exactly the rational
Weierstrass points

```text
u = 2, 4, 14/3.
```

Since `Jac(Q)` is generated by rational 2-torsion and has rank zero, any
rational point maps to a 2-torsion class relative to a rational Weierstrass
base point.  On a genus-2 hyperelliptic curve, this forces the point itself to
be Weierstrass.  Hence the three points above are all rational points on the
quotient.

## Lifting Back

The relation between `R` and `u` is

```text
3R^2 - 3uR + 5u - 7 = 0.
```

For the three quotient points:

```text
u = 2      -> R = 1, and y = +/-16 on C_-.
u = 4      -> 3R^2 - 12R + 13 = 0, no rational R.
u = 14/3   -> R = 7/3, but f_-(7/3) = -1280/2187 is not a square.
```

Therefore

```text
C_-(Q) = {(1,16), (1,-16)}.
```

Using the branch isomorphism, this gives

```text
C_+(Q) = {(7/3, 16/81), (7/3, -16/81)}.
```

Both are boundary points of the original order-30 family: they correspond to
`t=-1`, where the contact-5 normalization has `c=0`.

## Conclusion

The quadratic-splitting route for extra independent `2`-torsion gives no
nonboundary rational specialization in the order-30 family.  In other words,
the `Q2`-splitting genus-3 square conditions are completely accounted for by
boundary points.

This does not analyze the separate `C3` rational-root condition; that condition
is an irreducible degree `(20,3)` plane curve in `(R,rho)` and remains a
different, harder extra-2 route.
