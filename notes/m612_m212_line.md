# Independent `3`-torsion on the simple `M(2,12)` line

Audit date: 2026-07-10.

## Result

The one-parameter simple `[2,12]` family does not produce a smooth candidate
for `[6,12]` at naive rational height at most `100000`.

More precisely, I derived the exact cubic-contact cover for an independent
rational order-`3` direction, computed its finite-field support directly
without Magma, and built a projective CRT sieve.  Among every primitive

```text
r = n/d,   |n| <= 100000,   1 <= d <= 100000,
```

the only parameters surviving the exact contact masks through `p=89` are

```text
r = 0, 1, -1.
```

All three are singular/degenerate fibers.  There are therefore no smooth
parameters to send to exact `TorsionSubgroup`, and no Magma search was run.

This is a rigorous bounded exclusion, not a global nonexistence theorem.


## The line `z=+/-r`

The standard `M(2,12)` chart is

```text
a = (1-z^2)/(4*(r+1)).
```

The simple one-parameter `[2,12]` component is

```text
a = (1-r)/4.
```

Equating them gives

```text
1-z^2 = (1-r)(1+r) = 1-r^2,
```

and hence exactly

```text
z^2 = r^2,  i.e. z=+r or z=-r.
```

The two signs select the two roots of `T+1` and give the same curve.  I use
`z=r`, for which the selected root is `x=2`.

Write

```text
T = (1-r)/4*x^2-x+r,
h = (x-r)*(T+1),
W_r = h^2+(1-r)*x^2*T*(T+1).
```

Thus the completed-square curve is `Y^2=W_r(x)`.  Up to its displayed
nonzero leading scalar, its factorization is

```text
W_r = (1-r)^2*(2-r)/16
      * (x-2)
      * (x+2*r/(r-2))
      * (x+(2*r+2)/(r-1))
      * (x^3+4/(r-1)*x^2
           -(r^2+5*r+2)/(r-1)*x
           +2*r*(r+1)/(r-1)).
```

The three rational branch points give the independent rational `2`-class;
the marked `M(12)` class supplies order `12`.  Generic fibers therefore
contain `[2,12]`, and the sample `r=-25` has the existing irreducible local
`L`-polynomial simplicity certificate at `p=11`.


## Exact cubic-contact cover

Besides `x=2`, put

```text
u = 2*r/(2-r).
```

The coordinate

```text
X = (x-u)/(x-2),       x = (2*X-u)/(X-1)
```

sends `u` to `0` and `2` to infinity.  The exact odd model is

```text
F_r(X) = (X-1)^6 * W_r((2*X-u)/(X-1)).                 (1)
```

It has degree `5` and `F_r(0)=0` away from the coordinate boundary.

Let

```text
F_r = c5*X^5+c4*X^4+c3*X^3+c2*X^2+c1*X.
```

A nonzero rational order-`3` direction on this odd genus-2 model has a cubic
contact identity

```text
h3(X)^2-F_r(X) = m^2*q(X)^3,                            (2)
q = X^2+U*X+v^2,
h3 = m*X^3+N*X^2+R*X+m*v^3.
```

The square parametrization of the constant coefficient loses no smooth
nonboundary rational contact: from the constant coefficient of (2),
`S^2=m^2*V^3`, and for `m*V != 0` this forces `V` to be a rational square.

Put `L=1/m` and define

```text
B     = c5*L^2+3*U,
Delta = 4*c4*L^2+12*(U^2+v^2)-B^2.
```

The `X^5` and `X^4` coefficients give

```text
N = B/(2*L),       R = Delta/(8*L).
```

The remaining exact eliminated cover consists of three equations in
`(r,L,U,v)`:

```text
E3 = B*Delta+16*v^3-8*c3*L^2-8*U^3-48*U*v^2 = 0,

E2 = Delta^2+64*B*v^3-64*c2*L^2
     -192*(U^2*v^2+v^4) = 0,

E1 = Delta*v^3-4*c1*L^2-12*U*v^4 = 0.                 (3)
```

Equations (1) and (3) are the requested exact one-variable contact cover.
The Magma derivation/writer is

```text
code/m612_m212_line_contact_cover.m
```

and does not itself launch a search.

The built-in order-`3` class `4D` has `q`-support

```text
U0   = -2*(2*r^2-3*r+2)/(2-r),
v0^2 = r^2/(2-r)^2.                                   (4)
```

This follows by transforming the generic representative from
`notes/m212_three_torsion.md`.  An independent order-`3` class must have

```text
(U,v^2) != (U0,v0^2).
```


## Why finite cubic-contact counting is an exact necessary test

For an odd genus-2 curve, an order-`3` class cannot have reduced Mumford
degree `1`: that would make `3(P-infinity)` principal, but
`L(3*infinity)=<1,x>`.  Every nonzero order-`3` direction therefore has a
monic quadratic support `q`, and (2) is the corresponding function identity.

The two signs of a class have the same `q`.  Thus a one-dimensional rational
`3`-torsion space gives one support, while a two-dimensional space gives four
supports.  Since the marked order-`12` class already supplies one support, a
second distinct support is a necessary condition for `[3,12]`, hence for
`[6,12]` on this line.

At a good prime `p != 3`, reduction is injective on rational `3`-torsion.
Consequently, if a smooth rational fiber has an independent rational
order-`3` class, every good reduction must show at least two contact supports.

The script

```text
code/m612_m212_line_contact_sieve.py
```

enumerates the coefficient identity (2) over `F_p`.  For each `(U,V,m)`, the
`X^5,X^4,X^3` equations determine `(N,R,S)` triangularly, after which the
three low coefficients are checked.  It separately handles the small `m=0`
branch.  Hence it does not infer `3`-rank merely from the group order or the
Frobenius characteristic polynomial.


## The `p=5` boundary

On the projective parameter line at `p=5`, the affine data are

```text
r     model             number of contact q-supports
0     bad/singular      retained as boundary
1     bad/degenerate    retained as boundary
2     smooth            1
3     smooth            1
4=-1  bad/singular      retained as boundary
infty parameter pole    retained as boundary
```

Thus there is no smooth affine residue with a second `3`-direction.  Any
rational solution `r=n/d` in lowest terms must satisfy

```text
5 | n*d*(n-d)*(n+d).                                   (5)
```

So the line is **boundary-forced at `p=5`**, not proved locally dead.  The
four projective boundary classes `0,1,-1,infinity` were all retained; no
claim is made here that every one lifts to a `Q_5` point of the residual
contact cover.

The line is even more constrained than the ambient `M(2,12)` chart:

```text
p=7:  no smooth residue has a second support;
      allowed affine boundary residues are 0,1,5,6.

p=11: no smooth residue has a second support;
      allowed affine boundary residues are 0,1,10.
```

Thus a global rational extra-`3` point on this line would have to lie on
parameter/discriminant boundary classes at `5`, `7`, and `11` simultaneously.
This does not by itself prove a local obstruction, since the boundary class
may differ from prime to prime.

Complete masks through `59` and from `61` through `89` are recorded in

```text
data/m612_m212_line_masks_p59.txt
data/m612_m212_line_masks_p61_89.txt
```

At every prime, every bad affine residue and the projective infinity residue
were conservatively allowed.  Smooth residues were retained exactly when the
finite odd model had at least two cubic-contact supports.


## Height-`100000` projective CRT sieve

The fast enumerator is

```text
code/m612_m212_line_height_sieve.c
```

Run from `torsion_jac` with

```text
cc -O3 -march=native code/m612_m212_line_height_sieve.c \
   -o /private/tmp/m612_m212_line_height_sieve

/private/tmp/m612_m212_line_height_sieve 100000
```

It combines the especially strong `p=5,11,41,53` masks by CRT before
visiting a numerator.  If `p|d`, it retains the projective infinity class
and permits every `n mod p` compatible with primitivity.  Thus parameter
poles are not silently discarded.  Remaining masks are applied in density
order.

The exact output summary is

```text

SURVIVOR n=1  d=1 r=1/1
SURVIVOR n=-1 d=1 r=-1/1

DONE H=100000 leaves=100216016 bounded=167729174
     primitive=107194256 survivors=3
```

The full kill-count summary is in

```text
data/m612_m212_line_height_h100000_summary.txt
```

The three survivors are precisely degenerate fibers:

- `r=0`: rational factors collide at `x=0`;
- `r=1`: `a=0` and the model collapses;
- `r=-1`: rational factors collide at `x=0`.

Therefore no smooth rational parameter of naive height at most `100000`
passes the necessary independent-`3` conditions.


## Consequence for `[6,12]`

On a smooth member of this line, the built-in group is `[2,12]`.  An
independent rational order-`3` class would combine with its independent
order-`2` class to give `[6,12]`.  The bounded result shows that this elegant
one-parameter route has no candidate at a height far beyond the earlier
two-parameter searches.

This line should therefore be deprioritized relative to:

1. halving a rational `2`-class on the known geometrically simple `[6,6]`
   seed;
2. testing its rational Richelot neighbors for `2`-primary `[2,4]`;
3. deforming the explicit split HLP `[6,12]` seed while tracking both marked
   order-`12` classes.

The line is not globally eliminated: a point beyond height `100000`, or a
point living on a deeper projective boundary chart at every selected prime,
is not ruled out by this computation.
