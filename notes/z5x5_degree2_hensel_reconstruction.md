# Two-prime Hensel search on the degree-2 `[5,5]` contact cover

This is the bounded follow-up to
`notes/agent_z5x5_degree2_contact.md`.  It produced no rational curve, but
it exhausts all smooth open fiber branches over the two previously selected
base residue classes and gives a precise stopping point for that local pair.

## Files and exact runs

```text
code/z5x5_degree2_fiber_branches.sage
code/z5x5_degree2_hensel_reconstruct.sage
data/z5x5_degree2_fiber_branches_p11_p19.txt
data/z5x5_degree2_hensel_h30_p7_all_branches.txt
```

The recorded files were generated by:

```bash
sage code/z5x5_degree2_fiber_branches.sage --primes 11,19
sage code/z5x5_degree2_hensel_reconstruct.sage \
  --height-bound 30 --precision 7 --all-branches
```

The first command took about 32 seconds and the second about 48 seconds on
the current machine.

## Exhaustive finite fibers

The fixed base residues are the ones in the original finite probe:

```text
(a,b,k) = (0,0,4)  mod 11,
(a,b,k) = (1,3,16) mod 19.
```

For each prime the branch enumerator exhausts every pair

```text
q = x^2 + u*x + v,
R = r0 + r1*x + r2*x^2
```

with `disc(q) != 0`, `gcd(q,f)=gcd(q,R)=1`.  For every such pair it tests
whether `q^5+f*R^2` has a monic degree-5 square root `H`.  This is exhaustive
because the remaining coefficients of a monic `H` are uniquely recovered
from degrees 9 down to 5 before the identity is checked.

The exact counts are:

```text
             p=11       p=19
open q         110        342
candidate q,R 133100    2222316
open roots      100         16
smooth roots    100         16
```

Every root has invertible 10-by-10 fiber Jacobian.  The original recorded
roots occur as branch 9 modulo 11 and branch 0 modulo 19.

## Hensel and reconstruction bounds

The rational base enumeration is exact under the following declared bound:

```text
a,b,k = numerator/denominator in lowest terms,
|numerator| <= 30, 1 <= denominator <= 30,
gcd(denominator,11*19)=1,
with the two fixed residue triples above.
```

It gives 4 choices for `a`, 5 for `b`, and 6 for `k`, hence 120 bases.
For each base, every one of the `100*16=1600` cross-prime branch pairs was
uniquely lifted digit by digit through `11^7` and `19^7`.  The code checks
all ten residuals after each final lift.  Thus the run tested 192000 branch
pairs.

The combined modulus is

```text
11^7 = 19487171,
19^7 = 893871739,
M = 17419031429960369.
```

Standard rational reconstruction is therefore guaranteed for a reduced
coordinate `n/d` satisfying the symmetric bound
`|n|,d <= floor(sqrt(M/2)) = 93324786`, with denominator prime to `M`.
There were 280 branch pairs for which all ten fiber coordinates reconstructed
individually.  None of those 280 tuples satisfied the ten coefficient
equations over `QQ`.

Consequently there is no rational point in this search box which:

1. has one of the 120 bounded rational bases;
2. has good open reduction in the two fixed residue fibers; and
3. has all ten reduced fiber-coordinate numerator and denominator heights at
   most 93324786.

This is not a nonexistence result for rational `[5,5]` torsion.  It does not
cover other base residue triples, bad reduction at 11 or 19, boundary roots,
base height above 30, or fiber coordinates outside the reconstruction bound.

## Next justified search

Deeper lifting of these same 192000 pairs is low priority: the fiber height
bound already greatly exceeds the base bound.  The next bounded search should
vary the base residue cells:

1. Enumerate small rational bases `(a,b,k)` directly, starting with integer
   triples and then reduced fractions of a declared height.
2. Screen their reductions at two small good primes for `25 | #J(F_p)` and
   an irreducible 12th-power Frobenius transform.
3. Enumerate open contact branches only for bases passing both screens.
4. Hensel-lift all resulting branch pairs and apply the same exact
   reconstruction gate.

This changes the part of the search not tested here, while retaining the
finite, certifiable workflow.
