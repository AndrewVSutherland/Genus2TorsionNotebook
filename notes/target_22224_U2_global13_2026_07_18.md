## Exact projective scan

For a line `[a,b,c,d0*T^2]` and `[N:D]` in `P^1(Z/13^e)`, the integral
projective coefficient tuple is

```text
[a*D^2,b*D^2,c*D^2,d0*N^2].
```

Every primitive `[N:D]` has exactly one normal form:

1. `[t:1]`, with `t` modulo `13^e`;
2. `[1:13u]`, with `u` modulo `13^(e-1)`.

Thus the script checks all `13^e+13^(e-1)` projective classes at each depth.
It uses the identical `DeepKey` normalization as the existing repeated-fibre
deep filter and normalizes every bank row again at the requested depth.

This is an exact finite comparison with the supplied bank, independent of
Mordell--Weil generators or coefficient bounds.

## Interpretation and essential caveat

This result is **not a proof that U2 has no local 13-adic cubic-contact
branch**.  The 144-row bank is a collection of certified final-digit tangent
slices around sampled incidence centers; it is explicitly not exhaustive
over all p-adic components.

That distinction is especially important here.  The broader projected
contact calculation gave

```text
U2 at p=13: no finite T residue, infinity admitted.
```

The infinity key is `<0,0,0,1>`, and the depth-one list above shows that this
key is absent from the current tangent bank.  Therefore the zero intersection
primarily diagnoses a **coverage gap**: the existing bank contains none of
the projective infinity component relevant to U2.  It should not be read as
an obstruction supplied by that component.

The reciprocal U1 check reaches the same conclusion.  Increasing the U2
Mordell--Weil coefficient bound while using the present bank cannot help;
every possible `T` value misses it.  The meaningful next step for U2 is a
dedicated infinity-chart incidence/Hensel lift producing coefficient rows on
the `<0,0,0,1>` component, followed by this same global line comparison
against the enlarged bank.
