# The genus-7 discriminant cover at the known seed fiber

Fix

```text
s = 59/49
```

in the first-radicand quotient.  Put

```text
G(q) = q(s-q)(2-q^2+(q+2)s),
D(q) = Disc_U(U^3+(1+q)U^2+sU-(1+q)(q-s)).
```

Complete splitting of the complementary cubic forces a rational point on

```text
A: v^2=G(q), z^2=D(q).
```

This is the genus-7 `V4` cover.  The calculations are reproduced by

```text
code/elkies22210_orbit12_genus7_quotients.m
code/elkies22210_orbit12_genus7_mw_sieve.m
code/elkies22210_orbit12_genus7_mw_sieve.cpp
```

## 1. Quotient arithmetic

The three quotient curves have genera `1,2,4`:

```text
C_G:  v^2=G(q),
C_D:  z^2=D(q),
C_GD: y^2=G(q)D(q).
```

The elliptic factor is already known exactly:

```text
E(Q) = Z^2 + Z/4.
```

For the genus-2 factor, the points above `q=8/7` and `q=59/49` give
non-torsion divisor classes whose height-pairing determinant is

```text
21.309791275860305...
```

so they are independent.  Hyperelliptic 2-descent gives upper bound `3`.
For the genus-4 factor the seed gives a non-torsion divisor class, while
2-descent gives upper bound `2`.  Thus the currently obtained bounds are

```text
2 <= rank Jac(C_D)  <= 3,
1 <= rank Jac(C_GD) <= 2,
5 <= rank Jac(A)    <= 7.
```

The unified quotient script obtains both hyperelliptic upper bounds using
Magma's GRH class-group mode.  The genus-2 interval `2 <= rank <= 3` is
also certified independently with unconditional class-group bounds in
`code/elkies22210_orbit12_genus2_discriminant.m`; the genus-4 upper bound
`2` currently remains GRH-dependent.  The displayed points, their orders,
the height pairing, the elliptic rank, and the finite-field sieve below are
unconditional.  The genus-2 curve has no extra automorphism: its
automorphism group has order two, generated by the hyperelliptic involution.

The full fake 2-Selmer set of `C_D` has five classes.  Three are represented
by the known rational `q` values

```text
infinity, 8/7, 59/49.
```

A height-`10000` search on the integral genus-2 model finds exactly the
points over these three values.  This is useful evidence but not a global
point proof.

The genus-4 product quotient has the primitive integral model

```text
y^2 = 1129900996q^9-7188706847q^8+5744565372q^7
      +33182708370q^6-41331102120q^5-48218619491q^4
      +64606391416q^3+26876076480q^2-35080459776q.
```

Its polynomial factors over `Q` with degrees `1,1,2,5`; the quintic factor
is the irreducible discriminant polynomial.  A height-`1000` search finds
exactly five points: infinity, the Weierstrass values `q=0` and `q=59/49`,
and the two signs over the known seed `q=8/7`.  The seed gives a proven
non-torsion Jacobian class.  The GRH-assisted 2-descent upper bound is `2`;
no unconditional rank-`1` versus rank-`2` decision or extra lower-genus
quotient was obtained.

## 2. Discriminant-only Mordell--Weil sieve

Use the certified full Mordell--Weil basis

```text
P1 = (864/1225,182088/42875),
P2 = (-944/441,-367688/64827),
T  = (0,12744/2401), order 4.
```

For every good prime, reduce

```text
n1*P1+n2*P2+k*T
```

and retain it only when the corresponding value of `D(q)` is a square in
the residue field.  Points reducing to `q=infinity` are retained because
the leading coefficient of `D` is the square `4`; reductions at `q=0` are
tested literally.  Thus every rejection is a rigorous necessary local
obstruction to a rational point on `A`.

The C++ implementation exhausts

```text
|n1|,|n2| <= 2000, 0 <= k < 4,
```

or `64,032,004` Mordell--Weil elements, using 65 good primes from `11` to
`349`.  Only five coefficient triples survive:

```text
(-1, 1,0), (1,-1,0),
( 0, 0,1), (0, 0,2), (0,0,3).
```

The Magma implementation agrees exactly through bound `100`; eleven
chunked Magma runs independently exhaust bound `500`, or `4,008,004`
elements, and give the same list.

## 3. Exact survivors

The two signs of the non-torsion survivor give the known point

```text
q = 8/7,
roots = -1/7,-5/7,-9/7,
literal square mask = [true,false,false,false].
```

The point `2T` gives

```text
q = 59/49,
roots = 0,-1,-59/49,
```

which is boundary.  The points `T` and `3T` map to `q=infinity`, also
boundary.  In particular, the weaker discriminant condition produces no
surviving irreducible cyclic cubic, no second smooth split lift, and no
full four-radicand hit.

This is a finite-basis-box theorem, not a global determination of `A(Q)`.
It proves that any new point has

```text
max(|n1|,|n2|) > 2000
```

in the displayed full basis of `E(Q)`.

## 4. Attempted global completion

Over the quintic root field of the irreducible polynomial `D/4`, the
polynomial factors as a linear factor times a quartic.  Each of the five
fake 2-Selmer classes therefore leads to a genus-one quartic over that
quintic field, suitable in principle for elliptic Chabauty.  The three
known classes have visible points (at infinity, `8/7`, and `59/49`); the
other two have no point from the current search.  Magma's
`PseudoMordellWeilGroup` on even the first quintic-field elliptic curve did
not finish within the allotted run, so no global Chabauty certificate was
obtained.

The most direct global continuation is to finish the five quintic-field
Mordell--Weil computations on a larger-memory run and apply elliptic
Chabauty to the rational `q` map.  Alternatively, proving the expected
ranks `2` and `1` for the genus-2 and genus-4 factors would put the total
rank at `5<7`, opening classical quotient Chabauty on `A`.
