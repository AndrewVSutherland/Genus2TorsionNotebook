# Ari's compact split model for the `[2,2,2,12]` table row

Date: 2026-07-23.  Source: comment from Ari Shnidman on
`paper/torsion_realizations.tex`.

## The model

Ari proposed replacing the bulky `[2,2,2,12]` witness in the realization
table by

```text
y^2 = x (x - 120^2)(x - 143^2)(x - 266^2)(x - 218^2)(x - 241^2)
```

a monic sextic split over `Q` with all six roots perfect squares
(`0, 120^2, 143^2, 266^2, 218^2, 241^2`), so the full rational 2-torsion
`(Z/2)^4 ⊂ J[2]` is visible at a glance.

## IMPORTANT: this is a DIFFERENT curve, not a remodel

Checked in `scratchpad/verify_ari_full.m` (Magma, this session):

- `G2Invariants` differ from the previous displayed curve
  `y^2+(x^2+1)y = 756900x^6+...+830742747091037849`
  (the Richelot-BFS record curve of
  `notes/record_22212_richelot_bfs_2026_07_18.md`), so it is not even a
  twist of it;
- Euler factors differ at the common good prime `p=37`, so the two
  Jacobians are **not `Q`-isogenous** — Ari's curve is an independent
  witness, not a member of the old curve's Richelot tree (its `G2`
  invariants indeed do not occur in
  `results/record_22212_richelot_bfs_depth3.log`).

## Verification (fresh, this session)

- Exact torsion: `TorsionSubgroup` on
  `SimplifiedModel(ReducedMinimalWeierstrassModel(C))` gives invariants
  `[2, 2, 2, 12]`, order 96.
- `End(Jac_Qbar) = Z` certificate (standard pipeline of
  `code/claude_endz_certificates.m`):
  - root-power prime `p0 = 71`,
    `chi = x^4 - 8x^3 + 46x^2 - 568x + 5041`, irreducible with all root
    powers `pi^n` (`n <= 12`) of degree 4  =>  geometrically simple;
  - disjoint prime `q0 = 103`,
    `chi = x^4 - 4x^3 - 18x^2 - 412x + 10609`, splitting field linearly
    disjoint from that of `chi_{71}`  =>  center of `End^0` is `Q`
    (no RM/CM);
  - `#tors = 96 > 18`  =>  no quaternionic multiplication (LSSV 2024).
- Discriminant support:
  `2,3,5,7,11,13,17,19,23,41,73,109,193,241,263,409`.

Incidental structure among the square roots (why the model is
"enlightening"): several root differences are again squares or
`3 x square`, e.g. `218^2 - 120^2 = 182^2` and `241^2 - 120^2 = 209^2`
(Pythagorean triples `(120,182,218) = 2(60,91,109)` and `(120,209,241)`),
`218^2 - 143^2 = 3*95^2`, `266^2 - 241^2 = 3*65^2` — the visible
square/3-square difference pattern is what feeds the 4- and 3-parts of the
`Z/12` factor.
