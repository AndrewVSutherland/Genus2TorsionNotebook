# Contact-6 route toward `[3,6]` and `[6,6]`

This is the direct contact-6 route requested after discarding the split
`[2,2,2,6]` approach.

## Base contact-6 chart

Work with

```text
h6 = 1 + a*x + b*x^2 + x^3,
f  = h6^2 - (x - 1)^6.
```

Then

```text
f = (2*b + 6)*x^5
  + (2*a + b^2 - 15)*x^4
  + (2*a*b + 22)*x^3
  + (a^2 + 2*b - 15)*x^2
  + (2*a + 6)*x.
```

For smooth `f`, with `b != -3` and `h6(1)=a+b+2 != 0`, the function
`h6-y` has divisor

```text
6P - 6 infinity,    P = (1, a+b+2),
```

so `D=P-infinity` is a marked class of order dividing `6`, generically exact
order `6`.

This chart has one rational Weierstrass point built in, but not full rational
`2`-torsion.  It is therefore not the split `[2,2,2,6]` family.

## Adding independent `3`-torsion

Let

```text
q = x^2 + U*x + v^2,
h3 = m*x^3 + N*x^2 + R*x + S.
```

The cubic-contact condition

```text
h3^2 - f = m^2*q^3
```

gives a rational `3`-torsion class represented by `q`, provided

```text
m*v*(U^2 - 4*v^2) != 0,    gcd(q,f)=1.
```

Put `L=1/m`.  If `c_i` are the coefficients of

```text
f = c5*x^5 + c4*x^4 + c3*x^3 + c2*x^2 + c1*x,
```

define

```text
B     = c5*L^2 + 3*U,
Delta = 4*c4*L^2 + 12*(U^2+v^2) - B^2.
```

Then

```text
N = B/(2L),    R = Delta/(8L),    S = v^3/L,
```

and the remaining `[3,6]` cover is

```text
B*Delta + 16*v^3 - 8*c3*L^2 - 8*U^3 - 48*U*v^2 = 0,
Delta^2 + 64*B*v^3 - 64*c2*L^2 - 192*(U^2*v^2+v^4) = 0,
Delta*v^3 - 4*c1*L^2 - 12*U*v^4 = 0.
```

Together with exact order of `D` and independence of this `3`-torsion class
from `2D`, this gives the desired `[3,6]` condition on the contact-6 chart.

## Halving to target `[6,6]`

To halve the new `3`-torsion class, introduce

```text
u   = x^2 + alpha*x + beta,
ell = l3*x^3 + l2*x^2 + l1*x + l0.
```

The halving equations are

```text
ell^2 - f = l3^2*u^2*q,
ell + h3 == 0 mod q.
```

Equivalently, take the six coefficients of

```text
ell^2 - f - l3^2*u^2*q
```

in degrees `0..5`, and the two coefficients of

```text
8L*ell + (8*x^3 + 4*B*x^2 + Delta*x + 8*v^3) mod q.
```

The sign in the congruence only chooses `E` or `-E`; since `E` has order `3`,
existence of a rational half is unaffected.  On a specialization, the final
check for `[6,6]` is that `TorsionSubgroup(J)` has two invariant factors
divisible by `6`.

```text

```

and written to

```text

```

## Current status

This is a prospective algebraic route in the right sense: it starts from a
non-split contact-6 chart, imposes an independent cubic-contact `3`-torsion
class, and has explicit halving equations for `[6,6]`.

The initial searches are negative.  In this normalized chart, the small
rational cubic-contact points found so far are boundary points with `b=-3`.
The next useful step is therefore component analysis of the three `[3,6]`
equations, especially after eliminating `a`, to test whether the nonboundary
part is empty/very thin or whether it has a parametrizable component worth
feeding into the halving equations.

## Extra-root route for genuine `[6,6]`

Raw halving of an independent rational `3`-torsion class is not enough by
itself in this chart.  Since `f(0)=0`, the Jacobian already has one rational
`2`-torsion class `T0=(0,0)-infinity`.  Any rational `3`-torsion class `E`
has a rational half in the odd part, and adding `T0` gives an order-6 point,
but its `2`-part is the same as the marked order-6 class.  For genuine
`[6,6]`, the second order-6 point must have an independent rational `2`-part.

The algebraic way to impose this is to force a second rational Weierstrass
point.  Write

```text
h6(r) = eps*(r-1)^3,    eps in {+1,-1},    r != 0,1.
```

This gives

```text
a = (eps*(r-1)^3 - 1 - r^3 - b*r^2)/r.
```

Then the curve has rational roots `0` and `r`, so after adding an independent
`3`-torsion class the expected torsion is genuinely `[6,6]` rather than just
one shared `2`-part.

```text

```

For fixed `(eps,r,L,U,v)`, the first cubic-contact equation is quadratic in
`b`; the script solves this quadratic and checks the remaining two contact
equations exactly.  This is much narrower than scanning `(a,b)`.

Current conclusion: the `[2,6,6]` torsion equations do not globally force the
whole extra-root/cubic-contact variety into the decomposable locus.  But the
small rational components/branches we are currently hitting do lie in a very
explicit split locus with an extra involution and degree-2 elliptic subcovers.
A simple `[2,6,6]` example, if it exists in this framework, must come from a
non-automorphic branch, not from the branch producing the known examples.

I also tried a simple-only height-30 search.  The naive version got caught in
hard exact torsion computations.  I then changed the script so that, when

simplicity before exact torsion.  Even with stronger finite filters through
`p=67`, the run again hit hard early exact computations before producing a
simple hit, so I stopped it rather than leave a long Magma process running.

A useful structural point: forcing the second rational root always gives at
least three rational finite roots, because

```text
f = (h6 - (x-1)^3)*(h6 + (x-1)^3),
```

and one of these factors already contains the root `x=0`.  Thus the attempted
factor-type `[1,1,3]` filter is impossible in this chart; the found `[6,6]`
examples have factor type `[1,1,1,2]`.



## Core-cover search with factor type `[1,2,2]`

The better route for simple examples is not to force another rational root.
The contact-6 polynomial factors as

```text
f = x*((b+3)*x^2 + (a-3)*x + 2)
      *(2*x^2 + (b-3)*x + (a+3)).
```

Thus, when the two quadratics are irreducible, the curve has factor type
`[1,2,2]` and rational `2`-rank `2`, without falling into the many-rational-root
extra-root locus.  An independent rational `3`-torsion class on this locus is
therefore enough to produce `[6,6]`.

For the generic branch `v^3 != 1`, I used the linearity of `F1` in `a` to solve
for `a`, then fixed rational slices `(b,v)` and solved the two remaining
equations in `(M,U)`, with `M=L^2`.  This is implemented in

```text

```

The script verifies exact torsion on integral models and applies a good-prime
irreducibility certificate for geometric simplicity.

## Infinite-family attempt on the `[6,6]` core surface

The generic branch after eliminating `a` gives a two-equation algebraic base

```text
G2(b,L,U,v) = G3(b,L,U,v) = 0,
a = N/(8*L^2*(v^3-1)),
```

with the usual open conditions

```text
L*v*(v^3-1)*(U^2-4*v^2)*(b+3)*(a+b+2) != 0.
```

Together with the factor type `[1,2,2]`, this is a positive-dimensional
algebraic family whose generic member has rational torsion containing `[6,6]`

## Halving the marked order-6 class toward `[3,12]`

To go from the `[3,6]` construction to `[3,12]`, the natural target is to
halve the marked contact-6 class

```text
D = P - infinity,    P=(1,h6(1)).
```

Use the centered coordinate `t=x-1` and write

```text
h6 = t^3 + A*t^2 + B*t + C,
A = b+3,   C = a+b+2,   B = A+C-2.
```

Then

```text
f = h6^2 - t^6.
```

A rational half `H` of `D` is represented by

```text
u   = t^2 + p*t + q,
ell = r*t^2 + s*t - C,
```

with

```text
ell^2 - f = -2*A*t*u^2.
```

The sign `ell(0)=-C` makes the residual point `(0,-C)`, hence `2H=D`.  The
opposite sign is equivalent after replacing `H` by `-H`.

Equating coefficients gives four equations:

```text
H1 = A*q^2 - C*(B+s) = 0,
H2 = -2*A*C + 4*A*p*q - B^2 - 2*C*r + s^2 = 0,
H3 = -2*A*B + 2*A*p^2 + 4*A*q - 2*C + 2*r*s = 0,
H4 = -A^2 + 4*A*p - 2*B + r^2 = 0.
```

On the open chart `A*C != 0`, two variables eliminate immediately:

```text
p = (A^2 + 2*B - r^2)/(4*A),
s = A*q^2/C - B.
```

The two remaining equations in `(A,C,q,r)` are written by

```text
code/contact6_m36_halveD_symbolic.m
data/contact6_m36_halveD_symbolic.txt
```

This is the algebraic halving cover of the contact-6 marked class.  It is the
same two-dimensional family as the standard `M(2,12)` chart

```text
m = (1-z^2)/(4*(r+1)),
T = m*x^2 - x + r,
Y^2 = (x-r)^2*(T+1)^2 + 4*m*x^2*T*(T+1),
```

where the marked class has order `12`.  Adding an independent rational
`3`-torsion direction then gives the desired target `[3,12]`.

The search script is

```text
code/contact6_m36_halveD_m312_search.m
```

It uses the algebraic halving chart above, then filters rational `(z,r)` by
the necessary finite condition that `J(F_p)` contain a subgroup compatible
with `[3,12]` at every good prime `p != 2,3`.  It then applies a geometric
simple certificate from an irreducible local `L`-polynomial before exact
`TorsionSubgroup` computations.

The finite table already shows a strong obstruction on the good open chart:

```text
p=5: allowed_312 0, bad 19, good rank counts [<1,6>].
```

Thus any rational `[3,12]` example in this halved-contact chart must reduce to
the bad/boundary locus modulo `5`.

The height-30 run

```text
data/contact6_m36_halveD_m312_h30_p43.txt
```

checked `1234321` rational pairs, with `614386` distinct `(m,r)` values.  It
found `14` residue survivors and `13` simple survivors; every exact simple
survivor had torsion `[12]`, and no simple `[3,12]` hit.

The deeper height-40 run

```text
data/contact6_m36_halveD_m312_h40_p43.txt
```

checked `3837681` rational pairs, with `1913946` distinct `(m,r)` values.  It
found `48` residue survivors and `45` simple survivors; again every exact
simple survivor had torsion `[12]`, and no simple `[3,12]` hit.

The known exact `[3,12]` specialization

```text
z=-5/3, r=-3/5, m=-10/9
```

appears as a residue survivor, but it is the previously identified split
nonsimple curve.  Under the simple-only target, it remains discarded.

Current conclusion: the algebraic route is correct and sharply reduced, but
small-height rational points on the simple locus appear to lose the extra
`3`-torsion at exact level.  The main prospective continuation is boundary
analysis at the obstructing prime `p=5`, rather than a wider blind height
search in the same open chart.



## Component-wise `p=5` boundary analysis for `[3,12]`

The boundary analysis is implemented in

```text

```

with the main height-40 output in

```text

```

Clearing denominators in the affine `(z,r)` chart over `F_5`, the sextic
discriminant factors as

```text
r^6*(r+1)^21*z^2*(z+1)^11*(z-1)^11*H(z,r),
```

where

```text
H = z^6*r^4 + 4*z^6*r^3 + 4*z^6*r^2
  + 3*z^4*r^4 + 3*z^4*r^3 + 4*z^4*r^2 + 4*z^4*r
  + z^2*r^4 + 3*z^2*r^3 + 2*z^2*r^2 + 4*z^2*r
  + z^2 + 4*r^2 + 3.
```

Thus the affine boundary components are


split `[3,12]` example reduces to
