## 0. One-paragraph summary

Chart 1 for `[2,2,16]` is: take the marked order-8 class `Q` on the odd
`M_1(8,2,2)` chart `f_{u,v}` and ask whether **any** of the 16 order-8 classes
`±Q+T`, `T ∈ J[2](Q)`, is divisible by 2. The eight cosets `Q+T` give **exactly
four** distinct `x−T` condition sets, which the `S_3` permuting the root triple
`{u, v, w = −(u+v+1)}` collapses to **exactly two** inequivalent "norm
surfaces": `Y0` (untwisted) and `Y1` (twisted). Before this lane only `Y0` had
ever been enumerated. Both are now swept to `H_u = H_k = 2000` by an exhaustive
conic-pencil sieve. The two boxes contain **15 rational points**, which are
only **6 distinct curves over Q**, and **every one of them has torsion exactly
`[2,2,8]`**: `0` of the `16` order-8 classes is 2-divisible on any of them. The
failure is *not* visible mod p (all 6 pass `64 | #J(F_p)` at 12 good primes) and
*not* visible in the rational norm condition (which holds identically for all
eight twists); it is exactly the quadratic-field condition, and this lane
reduces it to a single computable invariant `eps ∈ Q*/(Q*)^2` with
`halving ⟺ eps ∈ {1, D_K}`.

Two further results push past the box: the criterion is now available in
**closed form** (four explicit polynomial square conditions, no `x−T` module
and no number field, validated 60/60 — §5b), and a mod-`p` count over all
primes `≤ 113` shows there is **no local obstruction** anywhere, with the
field condition holding at exactly the predicted density `3/4` (§6b). So chart
1 cannot be closed by any finite-prime argument; if it is empty, the reason is
global.

**Lane verdict: chart 1 is a clean measured negative in the stated box, with
the obstruction identified, put in closed form, and shown not to be local. No
curve is claimed. Nothing needs certifying, because nothing was found.**

## 1. What the target is, and why this chart

`[2,2,16]` has order 64. Per the lane brief, `M_1(8,2,2)` is the only
configuration that can give **exact** `[2,2,16]` (I **took this as given**; see
§8). The chart is the odd (quintic) model

```
f_{u,v}(X) = ((1-u)X + 1)((1-v)X + 1)((u+v+2)X + 1) · q̃(X),
q̃ = −X² + B X − C,
B = u²v − u² + uv² − u − v² − v − 2,      C = u² + uv + v² + u + v + 1
```

with a marked rational class `Q` of order 8 at `X = −1`, `y = u·v·(u+v+1)`.
Factor type `[1,1,1,2]`, so `L = Q(x)/(f) = Q × Q × Q × K`, `K = Q[X]/(q̃_monic)`,
and the 2-rank is 3 — i.e. `J(Q)_tors ⊇ [2,2,8]` generically on the chart.
A rational half of any order-8 class is an order-16 rational torsion point,
so `[2,2,16] ⊆ J(Q)` **iff some order-8 class halves**.

The rational roots are `r1 = 1/(u−1)`, `r2 = 1/(v−1)`, `r3 = −1/(u+v+2)`; under
`X = 1/(x−1)` they correspond to the sextic-chart roots `u, v, w = −(u+v+1)`
(the fourth sextic root `x = 1` going to infinity). Hence the `S_3`.

### 5b. NEW: the whole criterion in closed form — no `x−T` module, no number field

`code/claude_ov_2216_closedform.m` (commit `cacf4b4`, log
`results/claude_ov_2216_closedform.log`), derived over `Q(u,v)` and then
**validated against the `delta` module + Magma `IsDivisibleBy` at 15 points ×
4 condition sets: 60/60, `CLOSED_FORM_VALIDATED`**.

Write `θ = (B + √D_K)/2`, `δ'_K = a + bθ`, `P := 2a + bB`, and let `s ∈ Q(u,v)`
be the exact square root of `N(δ'_K)/(u v (u+v+1))` (it exists because the norm
class is `u v (u+v+1)` for every twist, §2b). Then

> **`Q+T` is 2-divisible ⟺**
> `g12 = □`, `g13 = □`, `u·v·(u+v+1) = t²`, and
> `λ0·(P + 2 s t) = □` **or** `λ0·(P − 2 s t) = □`.

The ingredients are far more uniform than expected:

* **`λ0 = (u−1)(v−1)(u+v+2) = −(u−1)(v−1)(w−1)` for all four condition sets** —
  identical, and fully `S_3`-symmetric.
* `s = 1` for `T = 0`; otherwise, up to sign (which the `±` absorbs),
  `s_T = (r_i r_j)² / ((r_i −1)(r_j −1))` where `{r_i, r_j}` are the **two
  non-distinguished** roots of `{u, v, w}`:

  | set | distinguished root | `s` |
  |---|---|---|
  | 1 (surface 0) | — | `1` |
  | 2 | `w` | `u²v²/((u−1)(v−1))` |
  | 3 | `v` | `u²w²/((u−1)(w−1))` |
  | 4 (surface 1) | `u` | `v²w²/((v−1)(w−1))` |

For `T = 0` this is completely explicit and needs nothing but rational
arithmetic (independently re-verified 6/6 in Python with exact fractions):

```
(1)  u(u−1)·v(v−1)                    = □
(2)  u(u−1)·(u+v+1)(u+v+2)            = □
(3)  u·v·(u+v+1)                      = t²
(4)  (u−1)(v−1)(u+v+2)·(B + 2 ± 2t)   = □   for one of the two signs,
     B + 2 = (v−1)u² + (v²−1)u − v(v+1) = uv(1−w) − w(w+1)
```

A by-product worth keeping: `eps₊·eps₋ ≡ P² − 4s²t² mod squares`, and for
`T = 0` that factors,

```
D_K ≡ (uv + w) · ( (1−w)²·uv + w(1+w)² )   (mod squares),
```

which is a much smaller expression for the square class of `D_K = B² − 4C`.

`countB/countA` converges to **exactly 3/4** — e.g. `p=97: .754 / .761`,

**Consequence.** No `p`-adic reason for chart 1 to be empty exists below 113,

2-cover. That was the earlier note's suspicion; the **local half of it is now
measured rather than assumed**. I still do not claim the global half (§8.4).

## 8. What I did NOT check — read this before quoting anything above

1. **I did not verify the premise** that `M_1(8,2,2)` is the only configuration
   giving *exact* `[2,2,16]`. It was given in the lane brief and is used only
   to justify working on this chart at all; nothing in §2–§6 depends on it.
2. **No proof that the surfaces have no further rational points.** Everything
   here is a *box* statement: `ht(u) ≤ 2000`, `ht(k) ≤ 2000` (plus the
   height-20 direct `(u,v)` box). `Y0(Q)` is in fact known to be **infinite** —
   `notes/claude_top10_07_2216.md` §3 proves three `d = −2` fibres have rank 2.
   So "0 hits in a box" is the correct reading, and only that.
3. **No descent or Chabauty on the `eps` locus.** I derived the cover in closed
   form (§5b) and probed it locally (§6b), but I did **not** build it as a
   variety, did not factor it into components, and did not compute genus or
   rank of anything. §6b only rules out a *local* obstruction below `p = 113`;
   it says nothing about the global structure.
4. **No Brauer–Manin claim.** Six `eps` values with no visible pattern is not
   evidence of a uniform obstruction, and the `0/≈98` tally is suggestive, not
   a proof. The earlier note's "suspected Brauer–Manin on the 2-cover Z"
   remains a suspicion — what §6b adds is that it cannot be *p*-adic.
   I also did **not** dedupe the earlier note's 83 points to isomorphism
   classes, so the number of genuinely independent tests behind "0/98" is
   unknown and is smaller than 98 (mine alone: 15 points = 6 curves).
5. **Surfaces 2 and 3 were not swept in their own coordinates.** Justified for
   existence by the `S_3` argument (§2c, §4), but it does mean the *height
   region* covered is `{distinguished root of height ≤ 2000}`, not three
   independent boxes. A curve whose only halving twist has all three roots of
   large height is outside everything done here.
6. **The `H=4000` extension covers only `q ≤ 250`** (§7). Bands `q ≥ 251` were
   not run, deliberately. The saturation observed in band 1 is evidence, not
   proof, that they would find nothing.
7. **No simplicity certificates.** None are needed — no curve is claimed. The
   6 curves found have torsion `[2,2,8]`, are not results, and I did **not**
   test whether they are geometrically simple.
8. **The chart-2 symbolic parity audit was not attempted.** The lane brief
   offered it as a stretch goal. It concerns a *different* family (the twisted
   `(2,2,2,8)` family of `notes/claude_top10_07_2216.md` §2, where the "best
   `delta` = 1/5 square components" ceiling was observed over ~800 curves), and
   there was no time. It remains item 1 of that note's strategy list and is
   unaffected by anything here.

## 9. Ranked next moves on chart 1

1. **Build the 2-cover `Z` as a variety and decompose it.** §6b has ruled out
   the cheap answer (a local obstruction), so the remaining question is global.
   Substitute the conic parametrisation `v = A/(A−k²)` (surface 0) into the
   closed form of §5b to get `Z` as an explicit surface in `(u, k, t, y)`,
   eliminate, factor into components, saturate spurious branches, and run
   genus/rank on the interesting ones. If a component is genus ≥ 2 or has
   rank 0, chart 1 closes **outright** rather than by box exhaustion. The
   `component-boundary-analysis` skill is written for exactly this, and §5b
   gives it a clean input. **This is the only move that can end chart 1.**
2. **Do the Ш/Brauer bookkeeping on `Z`.** Because §6b shows `Z` is everywhere
   locally soluble in the tested range, the natural next object is the
   Brauer–Manin obstruction on `Z` (or a 2-descent on the rank-2 fibres of §7
   of the earlier note, where `Y(Q)` is infinite and explicitly parametrised —
   that gives *infinitely many* independent `eps` samples, which is a far
   better experiment than any box sweep).
3. **Finish `H=4000` on surface 1 and run surface 0 at `H=4000`** (§7).
   **Demoted by the band-1 measurement**: `q ≤ 250` at `H=4000` returned the
   same 6 curves and zero new points, so the height direction looks saturated.
   Do this only if idle cores would otherwise be wasted.
4. **A four-condition C sieve** is now possible (§5b: `t` is a modular square
   root wherever `uv(u+v+1)` is a QR, so the field condition is imposable
   mod `p`). Note however that §6b caps its value: the extra condition only
   removes `1/4` of survivors per prime, and the existing three-condition
   sieve is already essentially exact (15 survivors in `1.9×10^13` quadruples,
   0 false positives). It would clean up the pipeline, not speed it up.

   `{some root of height ≤ H}` rather than `{distinguished root of height ≤ H}`
