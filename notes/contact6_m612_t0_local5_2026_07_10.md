# The `T0` contact-6 pullback at `p=5`

Date: 2026-07-10.

## Conclusion

No genuine contact-open `Q_5` cone was found for the exact `T0`-halved
`[6,12]` pullback.

The strongest ordinary integral cone can be eliminated by two exact
deflations: its first exceptional fiber is a doubled line, and none of its
`16` open points lifts to the next deflated level.  The generic compensated
internal pole `v_5(omega)<0`, with `a+3` a unit, is also very constrained:
all `32` smooth residues remain on `U+2*nu=0` through all `20,000` exact
mod-`125` lifts.

This is not yet a proof that the whole `T0` route is `Q_5`-empty.  The
remaining gaps are lower-rank ordinary cones, compensated poles for which
`a+3` also has positive valuation, and weighted poles in `(L,U,nu)`.  The
present calculation does prove that there is no audited `p=5` slice mask to
feed into the rational search yet.

The last factor removes the geometrically split `omega=+/-1` locus.  It was
included in every corrected escape count below.

## The unique highest-rank escaping cone

All `80` rank-3 escaping mod-`25` lifts lie over the two `L`-sign variants
of

```text
(s,omega,m,L,U,nu) = (3,1,0,2,2,-1)  (mod 5).
```

Here

```text
(a,b)=(0,0),
DB=DC=0,
m=0,
U+2*nu=0,
omega^2-1=0,
RRred != 0                    (mod 5).
```

The four projected `(omega,nu)` pairs among the exact escaping mod-`25`
lifts are

```text
(6,19), (11,14), (16,9), (21,4)  (mod 25).
```

They are diagnostic only, not safe search masks: the cone dies after
deflation.

For the displayed `L=2` center put

```text
s     = 3  + 5*S,
omega = 1  + 5*O,
m     =      5*mu,
L     = 2  + 5*E,
U     = 2  + 5*V,
nu    = -1 + 5*N.
```

The original Jacobian has rank `3`; its first row, `Fhalf`, has zero
differential.  Divide `(F1,F2,F3)` by `5` and `Fhalf` by `25`.  On the first
exceptional fiber the exact transformed equations are

```text
S + O + 4*E + 2,
S + 4*E + 4*N + 2,
E + V + 4,
S^2 + S*O + 4*O^2 + 4*S + 2*O + 4.
```

Eliminating the first three turns the last equation into

```text
(E+2*O)^2=0.
```

The normalized discriminants are

```text
DB/5 = S+4*O+2,
DC/5 = S+2*O+2                 (mod 5).
```

The open exceptional points therefore have

```text
O=r, mu=q, E=3*r, S=2*r+3, V=1-3*r, N=-r,
r*q != 0.
```

There are `16` such points.  At every one, the next exact row deflation has
no `F_5` point at all.  Equivalently, none solves the first-deflated system
modulo `25`; in the original normalization the necessary precisions are
`F1,F2,F3 mod 125` and `Fhalf mod 625`.  The second `L` sign is identical by
the exact symmetry `L -> -L`.  Hence the entire rank-3 cone is excluded as a
source of an exact `Q_5` point.


## Auditing correction: the false provisional Hensel sample

An early provisional run incorrectly reported a rank-4 cone.  It used a
two-iterator Magma list directly in a matrix constructor, which laid out the
`4 x 6` Jacobian entries in the wrong order.  Explicit row concatenation
fixes the issue.

The purported point was

```text
x0   = (2,1,1,1,3,1)          (mod 5),
x25  = (12,6,21,1,23,21)      (mod 25).
```

Direct evaluation of `(Fhalf,F1,F2,F3)` at `x25` is

```text
(15,20,10,15)                 (mod 25),
```

so it is not a point.  The provisional local-mask changes to
`code/contact6_m612_t0_core_slice_search.m` were fully reverted.  No search
code in the repository assumes this false sample.


## Compensated internal poles in `omega`

Let

```text
alpha=v_5(s),  beta=v_5(omega),
gamma=v_5(a+3)=alpha+2*beta.
```

For affine-integral `(a,b)`, both `alpha` and `gamma` are nonnegative.  The
hidden internal-pole cone has `beta=-t<0`, hence `alpha>=2t`.  In the generic
case `gamma=0`, write

```text
s=5^(2t)*S,  omega=O/5^t,  S*O a unit.
```

Writing `delta=m^2-c4`, valuation comparison in `Fhalf` forces
`v_5(delta)>=t` in the unit-`m` branch.  Put `delta=5^t*D`.  The exact
halving equations become

```text
m^2-c4-5^t*D=0,

(8*S*(c3-4*5^t*S*O)-D^2)^2
    -256*S^2*m^2*(c2+O*D)=0.
```

Here

```text
a=S*O^2-3,  b=5^(2t)*S-3.
```

The mod-`5` fiber is the same for every `t>=1`.  Complete enumeration gives

```text
S,O-unit points                             168
full contact-open points                      0
Jacobian ranks              1:40, 2:80, 3:16, 5:32
rank-5 points                                32
rank-5 contact-open points                    0
```

Every rank-5 point has `U+2*nu=0`.  Exact affine-kernel lifting for
`t=1` gives

```text
rank-5 residues                              32
mod-25 lifts                                800
mod-125 lifts                             20000
lifts with U+2*nu nonzero mod 25              0
lifts with U+2*nu nonzero mod 125             0
```

Thus this generic compensated pole chart has no contact-open cone through
the tested depth.  This is strong evidence that its smooth residues belong
to the degenerate repeated-root `3`-direction, but the calculation does not
claim an all-orders proof.
