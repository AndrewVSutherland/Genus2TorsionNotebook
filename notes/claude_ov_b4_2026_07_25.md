**Date:** 2026-07-25 · **Machine:** claude-box (no AWS used) · **Lane tag:** `b4`
**Target:** a genus-2 curve over `Q` with `J(Q)_tors ⊇ Z/2 × Z/22` and `End(J) = Z`

## 0. The route in one paragraph

Flynn's order-11 family (J. Number Theory **36** (1990), Application 3.1), in the
repo's normalization,

```
F_t(x) = x^6 + 2x^5 + (2t+3)x^4 + 2x^3 + (t^2+1)x^2 + 2t(1-t)x + t^2
       = t^2 (x-1)^2 + 2t·x(x^3+1) + x^2(x^2+x+1)^2 ,
```

gives `y^2 = F_t(x)` with a rational point of order 11 on `J`. Measured here:
**every member of the quadratic-factor incidence variety that was sampled has
exact `J(Q)_tors = Z/22`** — 13 curves by Magma `TorsionSubgroup` (12 on the
`(4,3)` component, §2.4, and the `n = -1` seed on the `(6,2)` component together
with its Richelot codomain, §1.5). Members *off* that variety have factor type
`[6]` or `[3,3]`, hence 2-rank 0 and `J(Q)_tors = Z/11` (§4). So the target
reduces to **raising the rational 2-torsion rank from 1 to 2** while keeping the
11.

A Richelot `(2,2)`-isogeny preserves `End⁰` and the odd part of the torsion, so
the 11 and the genericity survive it. The recorded blocker ("2-rank-1 seeds have
no rational `(2,2)`-kernel") is wrong in general: a Richelot kernel need only be
**Galois-stable**, not pointwise rational. Route B4 = walk Richelot from the
order-11 stream and look for a codomain with 2-rank 2.

**Bottom line of the lane.** Route B4 over Flynn's family is now *structurally
closed*. The locus of members admitting a Galois-stable Richelot kernel is a
cover of the `t`-line with **exactly two irreducible components** — one of
genus 1 (`= 92.a1`, rank 1, infinitely many members) and one of genus 2
(finitely many) — and a permutation lemma proves that **only members with a
rational quadratic factor can ever have a codomain of 2-rank ≥ 2**, i.e. only
members on the quadratic-factor incidence variety, both of whose components are
now exhausted (both to `|n| ≤ 10^8` on the same curve `92.a1`, plus one
*proven* rank-0 kill). No `[2,22]` curve was produced. No local obstruction was
found either: the answer is "thin/finite", not "impossible".

## 2. What this session did — the `(4,3)` component, closed

### 2.1 A clean parametrization

Magma's `Parametrization(C, Place(p), P¹)` from the base point `(41/9 : 49/9 : 1)`
gives a degree-4 map whose denominator is `(s-44)²(s-68)²`; the substitution
`s = (68w/3 - 44)/(w/3 - 1)` reduces it to

```
u(w) = (2w³ - 2w² + 2w - 1)/w²
v(w) = ((w² - w + 1)/w)²                       (a perfect square)
t(w) = -((w-1)(w² - w + 1)/w²)²                (MINUS a perfect square)
```

verified from scratch (`C43(u,v) = 0` and `x² + u x + v | F_{t(w)}` exactly).
Writing `T = (w³-2w²+2w-1)/w²` we have `t = -T²`, `u = 2T + (2w²-2w+1)/w²`,
`v = ((w²-w+1)/w)²`; also `disc(x²+ux+v) = u² - 4v = -(4w³-4w²+4w-1)/w⁴`.

So **the `(4,3)` component is exactly the "`t` is minus a square" branch** of the
incidence variety, and on it `x²+ux+v = (z²+z/w+V)(z²-z/w+V)` after `x = z²`,
`V = (w²-w+1)/w`.

### 2.2 The generic member: factor type `[1,2,3]`

Over `Q(w)` (`results/claude_ov_b4_c43param.log`):

```
F_{t(w)} = L(x) · G1(x) · C(x),    deg 1, 2, 3
L  = x - ((w-1)/w)²
G1 = x² + u(w) x + v(w)
C  = x³ + (1-2T) x² + (1+T²) x - T²
```

— **not** the `[2,4]` of the `(6,2)` stream. Generic 2-rank is again 1
(`#even subsets = 4`), but now there is a **rational Weierstrass point**.

### 2.3 There is no Richelot to do here

The resolvent cubic of the quartic cofactor `L·C` is **irreducible over `Q(w)`**;
the corresponding `D4` cover is degree 3 of **genus 3**. Structurally: `L·C` has
exactly one rational root, so a Galois-stable pairing of its four roots must pair
that root with a Galois-*fixed* root of `C` — i.e. **`C` must have a rational
root**, which already makes the factor type `[1,1,2,2]` and the 2-rank 2. On the
`(4,3)` component, *"a Richelot isogeny exists" is the same condition as "the
2-rank is already 2"*; the Richelot step buys nothing.

Hence J(Q)[2] has rank ≥ 2 for a `(4,3)`-member **iff** one of:

**(i) `G1` splits.** `disc(G1)` square ⟺ a rational point on
`y² = -4w³ + 4w² - 4w + 1`. With `X = -4w`, `Y = 4y` this is
`Y² = X³+4X²+16X+16`, minimal model `[0,1,1,1,0]`, **conductor 19**:
`RankBounds = [0]`, `MordellWeilGroup = Z/3` **proven** (Magma, both flags true).
Magma `Points(bound 10^6)` on the direct model returns exactly
`(1:0:0), (0:1:1), (0:-1:1)` — i.e. `w = ∞` and `w = 0` only, and both are poles
of the parametrization. **No members. Unconditional.**

**(ii) `C` acquires a rational root.** In `T`, `C` is the *quadratic*
`(x-1)T² - 2x²T + x(x²+x+1)`, whose discriminant in `T` is exactly `x`. So
`x = ρ²` and `T = ρ(ρ²-ρ+1)/(ρ-1)` (the other sign is `ρ → -ρ`). Putting
`z = 1/(1-ρ)` turns this into the **symmetric** curve

```
C3 :  T(w) + T(z) = 0,   i.e.  (w³-2w²+2w-1)z² + (z³-2z²+2z-1)w² = 0
```

of bidegree (3,3), **genus 3** (Magma, both from the `(w,x)` model and the
symmetric model). Quotienting by the swap `(w,z) ↦ (z,w)` with `p = w+z`,
`q = wz` gives `p² - p(q²+2q) + (4q²-2q) = 0`, i.e.

```
y² = q⁴ + 4q³ - 12q² + 8q   (y = 2p - q² - 2q)
⟺  E : V² = X³ - 12X² + 32X + 64,   X = 8/q,  V = 8y/q²
```

whose minimal model is `[0,0,0,-1,1]`, **conductor 92, rank 1, trivial torsion** —
Magma `IsIsomorphic` says this is **the same curve `92.a1` that carries the
`(6,2)` component**. `E(Q) = Z·G` with `G = (8,8)`.

So `C3(Q) ↔ { n ∈ Z : δ(nG) = p² - 4q ∈ Q^{*2} }`.

### 3.1 …and the transverse component cannot help — a proof, not a search

`code/claude_ov_b4_permlemma.gp`, `results/claude_ov_b4_permlemma.log`.

**Permutation lemma (verified symbolically with generic `G_i`).** Write
`f = c·G1G2G3` with `G_i` monic quadratics whose *set* is Galois-stable, let
`Δ = det[coeffs]`, `H_i = G_j'G_k - G_jG_k'` for `(i,j,k)` cyclic, and
`f' = -H1H2H3/Δ`. Then for the transposition `(2 3)`:
`H1 ↦ -H1`, `H2 ↦ -H3`, `H3 ↦ -H2`, `Δ ↦ -Δ`, and for the 3-cycle the `H`-triple
is cyclically shifted with `Δ` fixed; in both cases `H1H2H3/Δ` is invariant
(which is *why* the codomain descends to `Q`). Each `H_i` has degree 2.
So **Galois permutes the three quadratic factors of `f'` by exactly the same
representation `ρ : Gal → S3` it uses on `{G1,G2,G3}`.**

**Structural theorem B.** If the Richelot codomain of such a member has
rational 2-torsion rank ≥ 2, then `F_t` has a **rational quadratic factor** —
i.e. the member lies on the quadratic-factor incidence variety `C62 ∪ C43`.

*Proof.* The non-transitive subgroups of `S3` are the trivial group and the
order-2 groups generated by a transposition; in either case some `G_i` is
Galois-stable, hence a rational quadratic factor of `F_t`. So assume `ρ` is
transitive. Then every Galois orbit on the six roots of `f'` has size divisible
by 3 (an element mapping to a 3-cycle moves each root out of its `H`-pair and
through all three), so the rational factor type of `f'` is `[6]` or `[3,3]`. In
both cases the number of even-degree subsets is 2, so the 2-rank of the codomain
is `log₂2 - 1 = 0`. ∎

**Consequence.** The genus-2 `D6` component is irrelevant to the target: a
member on it either has `ρ` transitive (codomain 2-rank 0, proved) or has a
rational quadratic factor and is therefore already inside the `(6,2)`/`(4,3)`
analysis. **Its unknown rational points do not have to be found.** This is
confirmed on all three of its known non-degenerate members (§4): factor type
`[6]`, 2-rank 0, torsion `Z/11`, every time.

**Net statement of the lane.**

> Route B4 over Flynn's order-11 family produces no `[2,22]` curve. The only
> members whose Richelot codomain can have 2-rank ≥ 2 are those on the
> quadratic-factor incidence variety, and there
>  * the `(4,3)` component has no Galois-stable kernel at all except on a
>    genus-3 locus whose `92.a1` quotient has been sieved to `|n| ≤ 10^8` with
>    only three degenerate survivors, and locus (i) is closed by a *proven*
>    rank-0 Mordell–Weil group;
>  * the `(6,2)` component is Richelot-able identically, and its three
>    necessary raise loci (genus 3, 3, 6) have been sieved to `|n| ≤ 10^8` with
>    only degenerate survivors, plus a 294-member direct walk with zero raises.
>
> The only remaining gaps are the two sieve bounds — not any missing case.

### 5.1 The two computations that would finish the lane unconditionally

Both are *sieve bounds*, not missing cases (theorem B removed the missing case).

1. **The `(4,3)` genus-3 curve `C3`.** It is bielliptic over `92.a1` (rank 1),
   so the set of `n` with `δ(nG)` square is exactly `C3(Q)`. A descent on the
   2-covering `C3 → E92` (determine the image of `δ` in `Q*/Q*²` from local
   conditions at 2, 19, 23) or Bruin's elliptic Chabauty should prove that only
   `n ∈ {0, ±2, 1}` occur. Currently: sieved to `|n| ≤ 10^8` (427 primes).
2. **The `(6,2)` raise loci** `A1`, `D1`, `W` (genus 3, 3, 6 double covers of
   `92.a1`). Same remark; currently sieved to `|n| ≤ 10^8`.

Not needed any more: the rational points of the genus-2 curve `C6`

## 6. What was NOT checked — read this before trusting anything above

1. **The `(4,3)` genus-3 curve `C3` is not *proven* to have only the degenerate
   points.** The sieve is exhaustive to `|n| ≤ 10^8` on the `92.a1` quotient
   (an astronomically strong height bound: `ĥ(nG) = 0.0498·n²`, so `n = 10^8`
   means canonical height `5·10^14`), but a sieve is not a proof. `C3` is
   bielliptic over a rank-1 curve, so elliptic Chabauty or a descent on the
   2-covering `C3 → E92` should settle it; **neither was run**.
   The same caveat applies to the `(6,2)` loci, also sieved to `|n| ≤ 10^8`.
2. **The genus-2 component's rational points were not determined.** Rank is
   exactly 2 = genus (`RankBounds [2,2]`, `RankBound 2`, `ReducedBasis` of size
   2 from 160 infinite-order points at `Bound 3000`), so classical Chabauty does
   not apply; no Mordell–Weil sieve was run. Its Jacobian is *split* (the
   L-polynomial is reducible over `Q` at all 58 good `p < 300`) but **I never
   found the elliptic quotient explicitly**: a Magma
   `GeometricAutomorphismGroup`/`AutomorphismGroup`/`CurveQuotient` job ran for
   ~10 minutes without output and was killed by PID, and a direct search over
   trace-zero Möbius involutions `σ(x) = (ax+b)/(cx-a)` with `|a|,|c| ≤ 30`,
   `|b| ≤ 60` found **no** bielliptic involution over `Q` — so if the splitting
   is geometric it is either by a larger involution or by a degree-3 map
   ((3,3)-split), which would fit the `D6` stabiliser. Theorem B (§3.1) makes
   all of this irrelevant to the `[2,22]` target, but the claim
   "`C6(Q)` = those 8 points" is **not** established; only
   `Points(bound = 10^5) = 8`.
3. **`End(J) = Z` was never certified for any `(4,3)` member.** No two-prime
   Frobenius certificate was computed in this lane at all. It was not needed
   (no `[2,22]` curve was produced), but the claim "the `(4,3)` stream is a
   generic order-22 stream" is *unverified* — I only measured the torsion.
4. **Only Flynn's family was considered.** Other parametrized order-11 families
   (DS-v2, the BLP `[1,1,2,2]` ansatz of route B2′) were not touched by this
   lane. The theorem in §3 is about `F_t` and nothing else.
5. **Only Richelot (`(2,2)`) isogenies.** Other 2-power isogenies, and
   `(2,2)`-isogenies whose codomain is a *product* of elliptic curves (which
   `RichelotIsogenousSurfaces` returns as `SetCart`/`Crv` rather than `JacHyp`),
   were not pursued as sources of new curves.
6. **No local-obstruction analysis.** Nothing here says `[2,22]` with `End = Z`
   is impossible; the measured picture is "thin and finite along this route".
7. The `w`-space raise search stops at `|a|,|b| ≤ 10^4`. The `(6,2)` sieve was
   re-run this session to `|n| ≤ 10^8` from the earlier instance's committed
   table (`results/claude_ov_b4_tab_main.txt`); I did **not** rebuild that table,
   so the correctness of the `A1`/`D1`/`W` locus functions rests on the earlier
   instance's `SELFTEST` block and its 73/74 validation against the direct walk.
8. The 12 `(4,3)`-torsion computations and the 16 total `TorsionSubgroup` calls
   used the integral-model rescaling `x → X/m, y → Y/m³` with `m` chosen prime by
   prime as `⌈-v_p(c_i)/(6-i)⌉`; Magma refuses non-integral models and the first
   version of the helper was wrong (it under-scaled and threw). Fixed and
   asserted.
